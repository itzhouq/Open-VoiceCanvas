## 已实现

### 产品事实统一

- 新增 `lib/product-catalog.ts`，集中维护当前页面价格、订阅额度、字符包、克隆/设计次数和播客初始整段计费倍率。支付发放继续使用相同数值的映射。
- 新增 `lib/trial-offer.ts`，沿用原试用环境变量、默认值和解析方式。首页、价格页、功能页、metadata、AI 摘要与配额模块读取同一配置。
- 服务器通过 Provider 向客户端传递试用字符数和天数；没有向客户端传递支付密钥、商品 ID 或其他服务器配置。
- 首页和价格页的试用卡及 FAQ 同步配置；$6 字符包显示与发放映射相同的 10,000 字符。
- 29 种界面的相关翻译统一为正确字符包数量、可替换的试用额度/期限及当前结账方式；移除未经验证的固定语言数量。
- 将“voice slots”改为消耗型 clone/design credits，说明创建声音与合成语音分别消耗额度，删除声音不返还已消耗次数。
- 说明播客首次整段生成使用确认对白字符数的两倍，单段编辑或重生成按该段字符数计算。倍率抽取没有改变原有扣费分支。

### 内容与可信度

- 四个公开功能页共 36 条决策 FAQ：TTS 9 条、克隆 9 条、故事 8 条、播客 10 条。
- 新增共用展示组件，包含用途说明、规格表、操作步骤、试用脚本、费用与限制、相关工具链接。
- FAQ 可见内容与 JSON-LD 由同一数据数组生成。
- 明确普通 TTS/克隆输出 MP3，故事/播客整段合并输出 WAV；区分粘贴文字与直接解析 PDF/Word。
- 去掉免费克隆、未经验证的音色/语言数量、绝对竞品判断、笼统商用及彻底删除承诺。
- 在价格页补充字符与单词、字符额度与克隆次数、播客倍率、有效期、支付及声音使用限制说明。
- 示例为明确标注的试用脚本，没有伪造已生成音频或使用未经证实的客户评价。
- README 和产品营销上下文同步当前功能与事实来源；历史指标明确标为历史信息。

### 抓取与索引

- 各路由管理独立标题，移除客户端通用标题覆盖和重复品牌后缀。
- 五个工具页保留可索引、自引用 canonical，并添加服务端可读取的用途与规格。
- 登录、重发验证邮件、找回/重置密码、邮箱验证、个人账户共六类页面设置 robots/googlebot 双 noindex，canonical 指向自身。
- robots 只禁止 `/api/`，允许搜索引擎读取账户页 noindex；没有变更训练爬虫的单独政策。
- sitemap 保留 14 个公开 canonical 页面，包含 `/app`；不再以构建时间伪装内容更新时间。
- 删除失效的 public robots/sitemap 副本。
- `/llms.txt` 与 `/llms-full.txt` 改为生成路由，从共享配置生成公开摘要；清除旧价格、模板评价、错误页文本和自嵌套快照。它们不包含会话或用户信息。

## 复跑

启动服务后：

```bash
npm run build
npm run start -- --port 3015 --hostname 127.0.0.1
# 另一个终端
npm run check:geo
```

检查其他地址时设置 `GEO_BASE_URL`。检查非默认试用配置时，服务使用 `TRIAL_TEMPORARY_QUOTA` / `TRIAL_DAYS`，检查脚本使用对应的 `GEO_TRIAL_CHARACTERS` / `GEO_TRIAL_DAYS`。这些值只作用于相应测试进程，不应通过修改生产配置来测试。
